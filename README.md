# Pokechill Companion

Pokechill Companion aide a choisir rapidement de bons contre-picks face a une equipe adverse dans [Pokechill](https://play-pokechill.github.io/).

Le projet permet de rechercher des Pokemon, composer une equipe ennemie, puis obtenir des recommandations offensives classees selon les matchups les plus favorables.

Le depot contient l'interface frontend et l'API backend qui alimente ce moteur de recommandation.
